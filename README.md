# Diffie-Hellman-Key-Exchange-by-samamahacks
Interactive Diffie-Hellman Key Exchange implementation in Python for secure shared-key generation and cryptography learning.

GitHub description ke liye ye better rahegi:

 > **An interactive Python implementation of the Diffie-Hellman Key Exchange. Users can enter the prime number, generator, and private keys to generate public keys and establish a shared secret, making it easy to understand the core concepts of cryptographic key exchange.**

 # Steps:

  Go to file named as Diffie-Hellman-Key-Exchange.py.  
 Copy the code.  
 Paste on any IDM(Vscode, pycharm, etc.  
 Run the code.
